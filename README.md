# 二進数バトル

勝つには、**相手の指の組み合わせが見えていないといけない**対戦ゲームです。
子供のころにやった指遊びを、指1本ずつではなく**桁として数える**形に作り替えました。

**▶ 遊ぶ： https://05.pineapp.jp/**（前のアドレス https://pineapp05.web.app/ と https://matsupine07.github.io/binary-battle/ からも、こちらへ移ります）

ブラウザだけで動きます。インストールも登録も要りません。ひとりで遊ぶときは、タイトルの「ひとりで あそぶ」を押してください。遊び方は、タイトルの「あそびかた」に絵つきで載っています。

---

## ルール

- お互い両手を使います。最初はどちらの手も **1**。
- 自分の手を押してから相手の手を押すと、**自分の手の数だけ相手の手が増えます**。
- **ちょうど31**（指が全部立つ）になった手は、たおれて使えなくなります。
- 31 を超えたときは **31 を引いて** 続けます（例：35 → 4）。
- **両手とも たおれたほうの負け**です。
- 200手たっても決着しなければ引き分けです。

指は左から **小指16・薬指8・中指4・人差し指2・親指1** の重みを持っていて、立っている指を足した数がその手の数になります。

対戦相手は「ひとりで（CPU）」と「ふたりで（1台の画面で交代）」から選べます。
指の上には 16・8・4・2・1 の札が出て、立っている指の札だけが光ります。手の絵は、作者が Piskel で描いたドット絵です。

> 2026-11-02 に、二進数で遊ぶだけのシンプルな形に作り直しました。前の版にあった「5本指モード」は外しています（前の版は git の履歴に残っています）。

## 中身について

**ゲームは HTML 1ファイル（`screen.html`）だけで動きます。**
ライブラリもフレームワークも使っていません。外へ読みに行くのは、文字の形（Google Fonts の DotGothic16）と、ページを置いている Cloudflare が自動で足すアクセス解析（Cloudflare Web Analytics）の小さなプログラムだけです。遊んだ中身はどこにも送りません。

| ファイル | 中身 |
|---|---|
| `screen.html` | ゲーム本体（タイトル・あそびかた・たいせんの3画面）。HTML・CSS・JavaScript が1ファイルに入っています |
| `terms.html` | 利用規約とプライバシー |
| `img/` | アイコンと、リンクを送ったときに出る見出し画像。`node tools/serve.mjs` → http://localhost:5605/tools/make-images.html で描き直せます |
| `tools/serve.mjs` | このフォルダを http://localhost:5605/ で見るための小さなサーバー（公開前の確かめ用） |
| `index.html` | 前のアドレス（GitHub Pages）から、新しいアドレス（https://05.pineapp.jp/）へ送るだけのページ |
| `_過去/step1.js` | 画面を付ける前の、動きだけを確かめていたころのもの |
| `テスト/` | テストとシミュレーション |

### テストを走らせる

```
node テスト/run-all.js
```

**6本・66項目**のテストが走ります。ブラウザは開きません。
`document` の偽物を用意して `screen.html` を読み込むので、**本体を1文字も変えずに**確かめられます。

```
node テスト/sim1-balance.js
```

こちらは自動対戦のシミュレーションです（数十秒かかります）。元の遊び方と二進数版で、手数と決着率がどう変わるかを測っています。

## 分かっていること・分かっていないこと

自動対戦2万回で測った結果です。

| | 元の遊び方（上限5） | 二進数版（上限31） |
|---|---|---|
| ランダムに打つ | 決着率 85.06% ／ 平均 10.4手 | 決着率 96.56% ／ 平均 73.8手 |
| 殺せるなら殺す | 決着率 99.13% ／ 平均 8.2手 | 決着率 95.17% ／ 平均 51.4手 |

- **手数は約7倍**になりました
- **打ち方によって、決着しにくいほうが入れ替わります**
- 決着しない対局は「長い」のではなく**本当に終わりません**（打ち切りを100倍にしても決着率が変わらないため）。なので200手で引き分けにしています

**まだ分かっていないこと**

- 人が遊んだときに何手かかるか（**まだ1件も集まっていません**）
- 面白いかどうか（測っていません）
- 3人以上での対戦（未実装）
- オンライン対戦（未実装）

# 二進数バトル

勝つには、**相手の指の組み合わせが見えていないといけない**対戦ゲームです。
子供のころにやった指遊びを、指1本ずつではなく**桁として数える**形に作り替えました。

**▶ 遊ぶ： https://matsupine07.github.io/binary-battle/**

ブラウザだけで動きます。インストールも登録も要りません。ひとりで遊ぶときは「CPU（Bを担当）」を押してください。

---

## ルール

- お互い両手を使います。最初はどちらの手も **1**。
- 自分の手で相手の手を選ぶと、**自分の手の数だけ相手の手が増えます**。
- **ちょうど31** になった手は死んで、使えなくなります。
- 31 を超えたときは **31 を引いて** 続けます（例：35 → 4）。
- **両手とも死んだほうの負け**です。
- 200手たっても決着しなければ引き分けです。

指は左から **小指16・薬指8・中指4・人差し指2・親指1** の重みを持っていて、立っている指を足した数がその手の数になります。

### 2つのモード

| モード | 片手の最大 | 死亡する数 |
|---|---|---|
| **二進数モード** | 31 | ちょうど31 |
| **5本指モード**（元の遊び方） | 5 | ちょうど5 |

対戦相手は「人間ふたり（1画面で交代）」と「CPU」から選べます。

## ★ 感想をいただけると助かります

プログラミングを学びながら、ひとりで作っています。
**「面白かった／面白くなかった」よりも、次の3つが分かるほうが直せます。**

1. **何手で終わりましたか。** あわせて、どのモードか（二進数／5本指）と、相手（CPU／人間）も書いていただけると助かります
   - 決着すると画面に「Aの勝ち！（12手）」のように手数が出ます
2. **ルールを読まずに始めて、どこで詰まりましたか。** 「何をすれば1手なのか分からなかった」など
3. **スマホで操作しにくかったところはありますか。**

置き場所は [Issues](../../issues) です。GitHubのアカウントが無ければ、note のコメントでも大丈夫です。

> **なぜ手数を聞くのか**：「31ちょうどを狙うのは5より難しいので、決着がつかないのでは」という心配があって、
> 自動対戦2万回で測ったところ **平均51〜74手** でした。ただ実際に人が遊んだ数字はまだ1件もありません。

## 中身について

**HTML 1ファイル（`screen.html`・約15KB）だけで動きます。**
ライブラリもフレームワークも使っていません。外部への通信も0件です。

| ファイル | 中身 |
|---|---|
| `screen.html` | ゲーム本体。HTML・CSS・JavaScript が1ファイルに入っています |
| `index.html` | `screen.html` へ送るだけのページ |
| `step1.js` | 画面を付ける前の、動きだけを確かめていたころのもの |
| `テスト/` | テストとシミュレーション |

### テストを走らせる

```
node テスト/run-all.js
```

**6本・100項目**のテストが走ります。ブラウザは開きません。
`document` の偽物を用意して `screen.html` を読み込むので、**本体を1文字も変えずに**確かめられます。

```
node テスト/sim1-balance.js
```

こちらは自動対戦のシミュレーションです（数十秒かかります）。元の遊び方と二進数版で、手数と決着率がどう変わるかを測っています。

## 分かっていること・分かっていないこと

自動対戦2万回で測った結果です。

| | 元の遊び方（上限5） | 二進数版（上限31） |
|---|---|---|
| ランダムに打つ | 決着率 85.06% ／ 平均 10.4手 | 決着率 96.56% ／ 平均 73.8手 |
| 殺せるなら殺す | 決着率 99.13% ／ 平均 8.2手 | 決着率 95.17% ／ 平均 51.4手 |

- **手数は約7倍**になりました
- **打ち方によって、決着しにくいほうが入れ替わります**
- 決着しない対局は「長い」のではなく**本当に終わりません**（打ち切りを100倍にしても決着率が変わらないため）。なので200手で引き分けにしています

**まだ分かっていないこと**

- 人が遊んだときに何手かかるか（**まだ1件も集まっていません**）
- 面白いかどうか（測っていません）
- 3人以上での対戦（未実装）
- オンライン対戦（未実装）
